# StudyShield Chrome extension (Manifest V3)
1. Unzip the download.
2. Open `chrome://extensions` and switch on **Developer mode**.
3. Click **Load unpacked** and choose this folder.
4. Click the StudyShield icon and press **Start focus mode**. Listed sites redirect to a "Stay focused" page, and YouTube hides Shorts and recommendations.

Note: a browser extension can only block websites in Chrome. It cannot block apps on your phone.
