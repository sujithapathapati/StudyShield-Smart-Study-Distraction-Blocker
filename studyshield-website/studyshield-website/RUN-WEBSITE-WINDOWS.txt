StudyShield website — run on Windows

1. Install Node.js LTS from https://nodejs.org/ if it is not installed.
2. Extract this ZIP. Open the extracted studyshield-website folder (the one containing package.json).
3. In File Explorer, open PowerShell in that folder.
4. Run these commands:

   npm install
   npm run dev -- --host 0.0.0.0 --port 8080

5. Keep PowerShell open and visit http://localhost:8080 in your browser.

The website connects to the StudyShield server at http://localhost:8081 by default.
Keep the backend and MongoDB running in their separate windows/containers. The backend is not included in this ZIP; it is in studyshield-backend.zip.
